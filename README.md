# 前台页面框架

这是根据 `REDESIGN_HANDOFF.md` 搭建的无依赖静态原型，用于确认页面结构、导航关系和响应式行为，不代表最终技术栈。

## 预览

在项目根目录运行：

```powershell
python -m http.server 4173 --directory framework
```

然后访问 `http://localhost:4173/`。

## 已覆盖页面

- 首页
- 团队介绍和成员详情
- 科研成果概览
- 论文、专利、项目列表
- 新闻动态和新闻详情
- 联系我们
- `admin.html`：后台信息管理平台交互原型（工作台、首页设置、团队介绍、科研成果、新闻动态、联系我们、网站外观、图片素材），与前台栏目一一对应；示例数据来自旧数据库，修改不会真实保存

公共页眉、科研成果下拉导航、移动端折叠菜单和页脚由 `assets/app.js` 统一生成。正式名称、Logo、团队照、成员照片和业务数据目前使用占位内容。

## 数据链（原型演示）

- `assets/site-data.js`：种子数据（后台与前台共用初始内容）。`settings.appearance` 存全站外观默认值（双 Logo、主色/强调色、标题/正文字体、页脚说明文字）。
- `assets/site-store.js`：把「草稿 / 已发布」副本存在浏览器 localStorage，并在前台 10 个页面按已发布数据渲染内容（成员、新闻详情页支持 `?id=` 参数）。
- 演示流程：打开 `admin.html` → 修改并**保存** → 右上角**发布更新** → 打开/刷新前台页面即可看到修改；工作台提供「重置演示数据」。
- 网站外观：后台「网站外观」页修改 Logo/站点名称/配色/字体/页脚文字，发布后由 `assets/app.js` 应用到全站 CSS 变量（页眉、Hero、导航高亮、页脚等随之变化）；「恢复默认外观」仅写草稿，发布后生效。
- 图片上传：后台所有图片入口统一走内置管线——自动纠正手机照片 EXIF 方向、弹窗交互裁剪（成员照片 4:5 / Logo 1:1 / 团队合照 16:6）、压缩后存草稿；编辑时回显已有图片，「移除图片」保存后置空。
- 注意：数据只存在当前浏览器里，换浏览器或清除站点数据会回到种子内容；正式实现将由数据库与构建流程取代。

## 首页动效

首页为自然滚动（2026-09-17 傍晚起：原全屏分节滚动与「数据统计」节已按需求移除），Hero 深色开屏保留满屏，含滚动渐入、顶部进度条与导航吸顶阴影；所有动效在系统开启「减少动态效果」（prefers-reduced-motion）时自动禁用。
